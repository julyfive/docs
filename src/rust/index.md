### 基础命令

 ```
 cargo --version/-V     检查 cargo 版本
 rustup --version/-V    检查 rustup 版本
 rustup show            查看已安装工具链
 rustup update          检查可用更新
 ```

### 升级rust

```
rustup update stable    更新稳定版本
rustup update 1.95.0    更新到指定版本
```

### 升级 rustup 自身

```
rustup self update
```
