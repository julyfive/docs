
# 数据类型

Rust 是静态类型语言，每个值都有确定的类型，并且 **不做隐式类型转换**。数据类型分为两大类：

| 分类     | 类型                   | 说明         |
|----------|------------------------|--------------|
| 标量类型 | 整数、浮点、布尔、字符 | 表示单个值   |
| 复合类型 | 元组、数组             | 多个值的组合 |

## 类型推断与注解

- 编译器通常能根据上下文推断类型，推断不出来时必须显式注解
- 整数默认 `i32`，浮点默认 `f64`
- `let` 支持 **shadowing**：可以重新绑定同名变量，并改变类型

```rust
fn main() {
    let a = 5; // 推断为 i32（整数默认）
    let b = 2.0; // 推断为 f64（浮点默认）
    let c: u8 = 255; // 无法从上下文推断时显式注解

    println!("{a} {b} {c}"); // 5 2 255

    let a = "shadow"; // shadowing：重新绑定，类型变为 &str
    println!("{a}"); // shadow
}
```

## 标量类型

标量类型只表示一个值，包括整数、浮点、布尔和字符。

### 整数类型

- 有符号整数以 `i` 开头（可存正负，补码表示），无符号整数以 `u` 开头（只能存非负）
- 名称后的数字表示位数，如 `i32` 是 32 位有符号整数
- `isize` / `usize` 的位宽等于目标平台的 **指针宽度**，常用于索引和长度
- 有符号范围：`-2^(n-1) ~ 2^(n-1)-1`；无符号范围：`0 ~ 2^n-1`

| 类型（有符号） | 取值范围                                   | 类型（无符号） | 取值范围                 | 长度    |
|----------------|--------------------------------------------|----------------|--------------------------|---------|
| i8             | -128 ~ 127                                 | u8             | 0 ~ 255                  | 8 bit   |
| i16            | -32768 ~ 32767                             | u16            | 0 ~ 65535                | 16 bit  |
| i32（默认）    | -2147483648 ~ 2147483647                   | u32            | 0 ~ 4294967295           | 32 bit  |
| i64            | -9223372036854775808 ~ 9223372036854775807 | u64            | 0 ~ 18446744073709551615 | 64 bit  |
| i128           | `-2^127` ~ `2^127-1`                       | u128           | 0 ~ `2^128-1`            | 128 bit |
| isize          | 取决于平台指针宽度                         | usize          | 取决于平台指针宽度       | arch    |

字面量写法：

| 形式     | 示例                    | 说明                   |
|----------|-------------------------|------------------------|
| 十进制   | `255`                   | 默认 `i32`             |
| 十六进制 | `0xFF`                  | 前缀 `0x`              |
| 八进制   | `0o377`                 | 前缀 `0o`              |
| 二进制   | `0b1111_1111`           | 前缀 `0b`              |
| 字节     | `b'A'`                  | `u8` 类型的字节字面量  |
| 类型后缀 | `42u8`、`1_000_000_u64` | 显式指定类型           |
| 分隔符   | `1_000_000`             | 下划线只用于提高可读性 |

```rust
fn main() {
    // 显式类型
    let _a: i8 = 127;
    let _b: u16 = 65535;
    let _c: i32 = -2147483648;
    let _d: u64 = 18_446_744_073_709_551_615;

    // 字面量形式
    let dec = 255; // 十进制，默认 i32
    let hex = 0xFF; // 十六进制
    let oct = 0o377; // 八进制
    let bin = 0b1111_1111; // 二进制
    let byte = b'A'; // 字节字面量，u8（65）

    // 后缀：显式指定类型
    let tiny = 127_i8;
    let big = 1_000_000_000_u64;
    let hex_suffix = 0xDEAD_BEEF_u32;

    // 平台相关：位宽等于指针宽度
    let index: usize = 10;
    let offset: isize = -4;

    println!("{dec} {hex} {oct} {bin} {byte}");
    println!("{tiny} {big} {hex_suffix} {index} {offset}");
}
```

下划线只能出现在数字之间，不能在开头或结尾：

```rust
fn main() {
    let ok = 1_000_000; // ✅ 数字之间任意位置
    // let err = 1_000_000_; // ❌ 不能以下划线结尾
    // let err2 = _1_000;    // ❌ 不能以下划线开头（会被当作标识符）
    println!("{ok}");
}
```

#### 算术运算

| 运算符 | 描述 | 逻辑               | 示例                  |
|--------|------|--------------------|-----------------------|
| +      | 加法 | 两个数相加         | 5 + 3 = 8             |
| -      | 减法 | 两个数相减         | 5 - 3 = 2             |
| *      | 乘法 | 两个数相乘         | 5 * 3 = 15            |
| /      | 除法 | 整数除法向零截断   | 5 / 2 = 2（不是 2.5） |
| %      | 取余 | 余数符号跟随被除数 | 5 % 3 = 2             |

整数除法是 **向零截断**（truncate toward zero），不是向下取整：

```rust
fn main() {
    println!("{}", 5 / 2); // 2
    println!("{}", -5 / 2); // -2（向零截断，不是 -3）
    println!("{}", 5 / -2); // -2
    println!("{}", -5 % 2); // -1（余数与被除数同号）
}
```

- 整数除数为 0 会在运行时 panic：`attempt to divide by zero`
- 字面量超出类型范围是 **编译错误**，例如 `let x: u8 = 256;`

#### 溢出处理

整数溢出的行为随构建模式变化：

- **debug 构建**：溢出立即 panic（`attempt to add with overflow`）
- **release 构建**：默认关闭溢出检查，按二进制补码回绕（`255u8 + 1` 得 `0`）
- 需要明确的溢出语义时，使用标准库提供的四种方法：

| 方法              | 行为                   | `255u8` 加 1 的结果 |
|-------------------|------------------------|---------------------|
| `wrapping_add`    | 回绕（补码语义）       | 0                   |
| `saturating_add`  | 饱和到类型边界         | 255                 |
| `checked_add`     | 溢出返回 `None`        | `None`              |
| `overflowing_add` | 同时返回结果与溢出标志 | `(0, true)`         |

```rust
fn main() {
    let x: u8 = 255;

    // let y = x + 1; // ❌ debug: panic；release: 回绕为 0

    println!("{}", x.wrapping_add(1)); // 0
    println!("{}", x.saturating_add(1)); // 255
    println!("{:?}", x.checked_add(1)); // None
    println!("{:?}", x.overflowing_add(1)); // (0, true)
}
```

#### 位运算

| 运算符 | 描述     | 逻辑                                   |
|--------|----------|----------------------------------------|
| &      | 按位与   | 两个位都为 1 时为 1，否则为 0          |
| \|     | 按位或   | 两个位有一个为 1 时为 1                |
| ^      | 按位异或 | 两个位相同为 0，不同为 1               |
| !      | 按位非   | 0 变 1，1 变 0                         |
| <<     | 左移     | 高位溢出丢弃，低位补 0                 |
| >>     | 右移     | 无符号补 0；有符号补符号位（算术右移） |

- Rust 的位运算 **不做隐式类型转换**，两个操作数必须是同一类型
- 移位数大于等于类型位宽时，debug 构建会 panic

```rust
fn main() {
    let a: u8 = 0b1010_1100;
    let b: u8 = 0b0110_0110;

    println!("{:08b}", a & b); // 00100100
    println!("{:08b}", a | b); // 11101110
    println!("{:08b}", a ^ b); // 11001010
    println!("{:08b}", !a); // 01010011
    println!("{:08b}", a << 1); // 01011000（最高位移出）
    println!("{:08b}", a >> 1); // 01010110
    println!("{}", -8i32 >> 1); // -4（算术右移，补符号位）
}
```

#### 常用方法

```rust
fn main() {
    println!("{}", i32::MAX); // 2147483647
    println!("{}", i8::MIN); // -128
    println!("{}", u8::BITS); // 8
    println!("{}", 2i32.pow(10)); // 1024
    println!("{}", (-5i32).abs()); // 5
    println!("{}", 10u32.max(3)); // 10
}
```

### 浮点类型

| 类型        | 大小             | 精度                      | 描述         |
|-------------|------------------|---------------------------|--------------|
| f32         | 4 字节（32 bit） | 约 6~7 位十进制有效数字   | 单精度浮点数 |
| f64（默认） | 8 字节（64 bit） | 约 15~17 位十进制有效数字 | 双精度浮点数 |

```rust
fn main() {
    let x: f32 = 1.0;
    let y = 2.5; // 默认 f64
    let sci = 1e10; // 科学计数法

    println!("{x} {y} {sci}");
}
```

#### 精度与比较

浮点数用二进制存储，`0.1`、`0.2` 这类十进制小数无法精确表示，直接比较可能得到意外结果：

```rust
fn main() {
    let a = 0.1 + 0.2;

    println!("{a}"); // 0.30000000000000004
    println!("{}", a == 0.3); // false ❌ 不要直接用 ==

    // ✅ 判断差值是否在可接受的误差范围内
    println!("{}", (a - 0.3).abs() < 1e-10); // true
}
```

浮点的特殊值（整数没有这些）：

```rust
fn main() {
    println!("{}", 1.0 / 0.0); // inf（浮点除零不会 panic）
    println!("{}", -1.0 / 0.0); // -inf
    println!("{}", 0.0 / 0.0); // NaN
    println!("{}", f64::NAN.is_nan()); // true
    println!("{}", f64::INFINITY); // inf
}
```

- `NaN` 与任何值都不相等（包括它自己），只能用 `is_nan()` 判断
- 浮点转整数用 `as`，会向零截断且饱和

### 布尔类型

| 类型 | 值           | 大小            | 描述                 |
|------|--------------|-----------------|----------------------|
| bool | true / false | 1 字节（8 bit） | 布尔值，只有两个取值 |

```rust
fn main() {
    let is_true: bool = true;
    let is_false = false;

    println!("{} {}", is_true, is_false); // true false
    println!("{}", is_true as u8); // 1（false 为 0）
}
```

- `bool` 可以 `as` 转成整数，但整数 **不能**隐式或 `as` 转成 `bool`
- 逻辑运算：`&&`（与）、`||`（或）、`!`（非），其中 `&&` 与 `||` 短路求值

### 字符类型

| 类型 | 大小             | 描述                |
|------|------------------|---------------------|
| char | 4 字节（32 bit） | 单个 Unicode 标量值 |

```rust
fn main() {
    let c: char = 'a';
    let cn: char = '中';
    let digit: char = '1';
    let emoji: char = '😀';

    println!("{c} {cn} {digit} {emoji}"); // a 中 1 😀

    println!("{}", std::mem::size_of::<char>()); // 4（固定 4 字节）
    println!("{}", '中'.len_utf8()); // 3（UTF-8 编码后占 3 字节）
    println!("{}", '中' as u32); // 20013（Unicode 码点）
    println!("{}", char::from_u32(20013).unwrap()); // 中（码点转字符）
}
```

- 字符用 **单引号**，字符串用双引号：`'a'` 是 `char`，`"a"` 是 `&str`
- `char` 固定占 4 字节，因为要容纳任意 Unicode 标量值（最大 `U+10FFFF`）
- 字符串的底层是 UTF-8 字节序列，一个字符可能占 1~4 字节（详见 String 章节）

## 复合类型

复合类型可以把多个值组合在一起，包括元组和数组。

### 元组 Tuple

- 长度固定，元素 **可以是不同类型**
- 用 `.0`、`.1` 按下标访问，索引必须是字面量
- 可以用模式匹配解构
- `()` 是空元组（单元类型），也是无返回值函数的返回类型

```rust
fn main() {
    let tup: (i32, f64, u8) = (500, 6.4, 1);

    // 解构：把元素绑定到变量
    let (x, y, z) = tup;
    println!("{x} {y} {z}"); // 500 6.4 1

    // 下标访问
    println!("{}", tup.0); // 500
    println!("{}", tup.2); // 1
    // println!("{}", tup[0]); // ❌ 元组不能用 [] 索引

    // 单元类型：空元组
    let unit: () = ();
    println!("{:?}", unit); // ()
}
```

### 数组 Array

- 长度固定，所有元素 **必须是同一类型**
- 类型写作 `[T; N]`，`N` 必须是编译期常量
- 越界访问会在运行时 panic，`get` 返回 `Option` 更安全
- 需要动态长度时使用 `Vec<T>`（见 Vector 章节）

```rust
fn main() {
    let a = [1, 2, 3]; // 长度推断为 3
    let b: [i32; 5] = [1, 2, 3, 4, 5];
    let c = [3; 5]; // 重复初始化：[3, 3, 3, 3, 3]

    println!("{}", a.len()); // 3
    println!("{}", b[0]); // 1
    println!("{:?}", c); // [3, 3, 3, 3, 3]

    // 安全访问：越界返回 None，不会 panic
    println!("{:?}", b.get(10)); // None

    // 切片：借用数组的一段
    let slice = &b[1..4];
    println!("{:?}", slice); // [2, 3, 4]
}
```

直接用下标越界会 panic：

```rust
fn main() {
    let a = [1, 2, 3];
    println!("{}", a[5]); // ❌ 运行时 panic: index out of bounds
}
```

## 类型转换

Rust 没有隐式数值转换，不同类型之间必须显式处理，常见方式如下。

### as 强制转换

`as` 是底层转换， **可能丢失数据**：

| 转换方向    | 行为                                            |
|-------------|-------------------------------------------------|
| 整数 → 整数 | 截断到目标宽度，按补码重新解释位模式            |
| 整数 → 浮点 | 可能丢失精度（如超大的 i64 转 f32）             |
| 浮点 → 整数 | 向零截断，`NaN` → 0，超出范围饱和（Rust 1.45+） |
| bool → 整数 | `true` → 1，`false` → 0                         |
| char → u32  | 得到 Unicode 码点                               |
| u8 → char   | 按 Latin-1 字节解码为字符                       |

```rust
fn main() {
    println!("{}", 300u16 as u8); // 44（300 截断为低 8 位）
    println!("{}", -1i8 as u8); // 255（按补码位模式重新解释）
    println!("{}", 3.9f64 as i32); // 3（向零截断）
    println!("{}", f64::NAN as i32); // 0（NaN 转 0）
    println!("{}", 65u8 as char); // A（Latin-1 解码）
    println!("{}", '中' as u32); // 20013
}
```

### From / Into / TryFrom / parse

- `From` / `Into`：保证成功且不丢失信息，如 `u8 → i32`
- `TryFrom`：可能失败的转换，返回 `Result`
- `parse`：把字符串解析为数字，本质是 `FromStr` trait

```rust
fn main() {
    // From / Into：安全转换
    let a = u16::from(255u8); // 255
    let b: i32 = 100u8.into(); // 100（Into 由 From 自动实现）

    // TryFrom：可能失败
    let ok = i8::try_from(100i32); // Ok(100)
    let err = i8::try_from(300i32); // Err(TryFromIntError)
    println!("{a} {b} {:?} {}", ok, err.is_err()); // 255 100 Ok(100) true

    // parse：字符串转数字
    let n: i32 = "42".parse().unwrap(); // 由变量类型推断目标类型
    let m = "42".parse::<i32>().unwrap(); // turbofish 显式指定目标类型
    let hex = i32::from_str_radix("FF", 16).unwrap(); // 255
    println!("{n} {m} {hex}");
}
```

- `parse::<i32>()` 里的 `::<i32>` 叫 turbofish，用来指定泛型参数
- 解析失败返回 `Err(ParseIntError)`，不要直接 `unwrap` 处理用户输入

## 常见错误一览

| 错误写法                    | 原因                   | 解决方式                      |
|-----------------------------|------------------------|-------------------------------|
| `let x: u8 = 256;`          | 字面量超出类型范围     | 编译期就会报错，换更大的类型  |
| `let x: i64 = 1i32;`        | 不做隐式转换           | `as i64` 或 `i64::from(1i32)` |
| `let a: [i32; 3] = [1, 2];` | 数组长度与类型不符     | 长度必须一致，或改用 `Vec`    |
| `a[10]`                     | 索引越界，运行时 panic | 用 `a.get(10)` 返回 `Option`  |
| `tup[0]`                    | 元组不支持 `[]` 索引   | 用 `tup.0`                    |
| `let x: i32;` 后直接使用    | 变量未初始化           | 使用前赋值                    |
| `"a"` 当作字符              | 双引号是字符串 `&str`  | 字符用单引号 `'a'`            |
| `0.1 + 0.2 == 0.3`          | 浮点精度误差           | 判断差值小于误差范围          |

```rust
fn main() {
    // 1. 不同整数类型不能直接比较
    // let bad = 1u8 == 1i32; // ❌ mismatched types
    let good = 1u8 as i32 == 1i32; // ✅ 显式转换

    // 2. 数组长度必须与类型标注一致
    // let arr: [i32; 3] = [1, 2]; // ❌ 期望 3 个元素

    // 3. 越界访问用 get 代替下标
    let arr = [1, 2, 3];
    assert_eq!(arr.get(3), None);

    // 4. 浮点比较使用误差范围
    assert!((0.1 + 0.2 - 0.3).abs() < 1e-10);

    println!("{good}"); // true
}
```

## 总结

- 标量类型：整数（`i`/`u` 加位数）、浮点（f32/f64）、布尔（bool）、字符（char）
- 整数默认 `i32`，浮点默认 `f64`；`usize` / `isize` 的宽度跟随平台指针
- 整数溢出：debug 构建 panic，release 构建回绕；用 `wrapping_*`、`saturating_*`、`checked_*` 明确语义
- 整数除法向零截断，除零 panic；浮点除零得到 `inf` / `NaN`，浮点不要直接用 `==` 比较
- `char` 是 4 字节的 Unicode 标量值，字符串是 UTF-8 字节序列，两者不要混淆
- 元组可存异构元素，数组要求同构，两者长度都固定；动态长度用 `Vec<T>`
- 没有隐式类型转换：`as` 可能截断，`From`/`Into` 安全，`TryFrom`/`parse` 可能失败
