# 数据类型

Rust中数据类型分为两大类: **标量类型** 和 **复合类型**

## 标量类型

整数 浮点 布尔 字符

### 整数类型

| 类型（有符号-正负） | 取值范围        | 类型（无符号-正） | 取值范围       | 长度   | 
|---------------------|-----------------|-------------------|----------------|--------|
| i8                  | -2^7--2^7+1     | u8                | 0--2^8-1       | 8bit   | 
| i16                 | -2^15--2^15+1   | u16               | 0--2^16-1      | 16bit  |
| i32（默认）         | -2^31--2^31+1   | u32               | 0--2^32-1      | 32bit  |
| i64                 | -2^63--2^63+1   | u64               | 0--2^64-1      | 64bit  |
| i128                | -2^127--2^127+1 | u128              | 0--2^128-1     | 128bit | 
| isize               | 取决于系统架构  | usize             | 取决于系统架构 | arch   |

arch 为系统架构，如 32 位系统为 i32, u32 等

写法的完整示例

```rust
fn main() {
    // === 类型写法 ===
    let _a: i8 = 127;
    let _b: u16 = 65535;
    let _c: i32 = -2147483648;
    let _d: u64 = 18_446_744_073_709_551_615u64;  // 后缀 + 分隔符
    
    // === 字面量写法 ===
    let dec = 255;                   // 十进制，默认 i32
    let hex = 0xFF;                  // 十六进制
    let oct = 0o377;                 // 八进制
    let bin = 0b1111_1111;           // 二进制
    let byte = b'A';                 // u8 类型（65）
    
    // === 带后缀 ===
    let tiny = 127_i8;
    let big = 1_000_000_000_u64;
    let hex_suffix = 0xDEAD_BEEF_u32;
    
    // === 特殊类型 ===
    let index: usize = 10;
    let offset: isize = -4;
    
    // === 从字符串 ===
    let parsed = "42".parse::<i32>().unwrap();
    let radix = i32::from_str_radix("FF", 16).unwrap();  // 255
    
    // === 类型转换 ===
    let x: u8 = 100;
    let y = x as i32;                // 100
    let z = i64::from(x);            // 100（用 From trait）
}

```

```rust
_ 不能放在开头或 结尾 
let ok = 1_000_000;     // ✅ 正确
let err = 1_000_000_;   // ❌ 错误（不能以_结尾）
let err2 = _1_000;      // ❌ 错误（不能以_开头）
```

```rust
// as：强制转换（可能截断或符号扩展）
let a = 300_u16 as u8;    // 44（截断）

// From：必须成功（编译期检查）
let b = u16::from(255_u8); // 总是成功

// parse：运行时解析（可能失败）
let c = "42".parse::<i32>(); // Result<i32, ParseIntError>

"42".parse::<i32>()
  ↑      ↑      ↑
  │      │      └── 类型参数：i32
  │      └── 泛型方法名
  └── 字符串对象

// parse 的定义是：
fn parse<F: FromStr>(&self) -> Result<F, F::Err>

// 所以调用时：
"42".parse::<i32>()  // 指定泛型 F = i32
```

##### 算术运算

| 运算符 | 描述 | 逻辑           | 实例              |
|--------|------|----------------|-------------------|
| +      | 加法 | 两个数相加     | 5+3=7             |
| -      | 减法 | 两个数相减     | 5-3=2             |
| *      | 乘法 | 两个数相乘     | 5*3=15            |
| /      | 除法 | 两个数相除     | 5/2=2 （不是2.5） |
| %      | 取余 | 两个数相除取余 | 5%3=2             |

整数相除是向下取整（向零舍入）

```rust
println!("{}", 5 / 2);   // 2
println!("{}", -5 / 2);  // -2（向零舍入，不是 -3）
println!("{}", 5 / -2);  // -2
```

##### 位运算符

| 运算符 | 描述     | 逻辑                            |
|--------|----------|---------------------------------|
| &      | 按位与   | 两位数位都为1时为1，否则为0     |
| \|     | 按位或   | 两位数位有一个为1时为1，否则为0 |
| ^      | 按位异或 | 两位数位相同为0，否则为1        |
| !      | 按位非   | 0变1，1变0                      |
| <<     | 左移     | 移动位数，低位补0               |
| >>     | 右移     | 移动位数，高位补0               |

rust中位运算必须是 **同类型**

### 浮点类型

```rust
let my_float:f32 = 1.0;
let my_float:f64 = 1.0;
```

| 类型（有符号） | 大小           | 描述       |
|----------------|----------------|------------|
| f32            | 4字节（32bit） | 32位浮点数 |
| f64（默认）    | 8字节（64bit） | 64位浮点数 |

<br>

### 布尔类型

```rust
let is_true:bool = true;
let is_false = false;
```

| 类型 | 值    | 大小          | 描述      |
|------|-------|---------------|-----------|
| bool | true  | 1字节（8bit） | 布尔值-真 |
| bool | false | 1字节（8bit） | 布尔值-假 |

<br>

### 字符类型

```rust
let c:char = 'a';
let c1:char = '中';
let c2:char = '1';
```

| 类型 | 大小           | 描述     |
|------|----------------|----------|
| char | 4字节（32bit） | 字符类型 |

<br>

<br>

## 复合类型

### Tuple

```rust
let tup:(i32,f64,u8) = (500,6.4,1);
let (x,y,z) = tup;
let my_tuple=('a',1,1.2,true);
let my_tuple1=my_tuple.0;
```

- 固定长度
- 元组元素可以不同类型

<br>

### Array

```rust
let my_array=[1,2,3];
let a:[i32;5] = [1,2,3,4,5];
let b:[3;5]; // [3,3,3,3,3]
let b_first=b[0];
```

- 固定长度
- 所有元素类型必须相同
