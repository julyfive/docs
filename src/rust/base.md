# 常用知识点

### 原码 反码 补码

计算机内部只有0和1

问：i8类型为啥负数可以到-128 正数却只能到127？

答：因为 0 占用了正数的一个编码位置，所以正数只有 127 个；而补码消灭了“-0”，把省下来的编码给了 -128，所以负数有 128 个。

| 二进制原码（以i8为例） | 二进制反码（以i8为例） | 二进制补码 （以i8为例）                                          | 代表数字                                | 分类                 |
|------------------------|------------------------|------------------------------------------------------------------|-----------------------------------------|----------------------|
| 0000 0000              | 0000 0000              | 0000 0000                                                        | 0                                       | 零                   |
| 0000 0001~0111 1111    | 0000 0001~0111 1111    | 0000 0001~0111 1111                                              | 1~127                                   | 正数（共 127 个）    | 
| 1000 0000              | 1111 1111              | 1 0000 0000（这里bit长度为9位，会被截断成八位，也就是0000 0000） | 0（由于截断，所以-0被截断成0），与0合并 | 零                   | 
| 1000 0001~1111 1111    | 1111 1110~1000 0000    | 1111 1111~1000 0001                                              | -1~-127                                 | 负数（共 127 个）    |
| 无                     | 无                     | 1000 0000                                                        | -128（乌龟的臀部，龟腚（规定））        | 负数（最特殊的一个） |

**规则：**

1. 二进制最高位为符号位，1为负数，0为正数
2. 正数的原码、反码、补码都一样（三码合一）
3. 负数的反码=它的原码符号位不变，其它位取反（0->1、1->0）
4. 负数的补码=它的反码加1、负数的反码=它的补码减1
5. 0的反码和补码都是0
6. 计算机在进行 **加减乘除** 运算时都是用补码进行运算的
7. 当我们要看运算结果的时候，我们要看原码
